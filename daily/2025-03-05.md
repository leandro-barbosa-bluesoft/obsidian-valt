Na tarefa [[389364]] conseguimos customizar o componente `FornecedorDivisaoComponent` adicionando o seguinte método:

	public FornecedorDivisaoComponent withMultiple() {  
    addAttribute("multiple", true);  
    return this;  
	}

Com isso o atributo `multiple` pode ser utilizado no arquivo do [[Velocity]] `fornecedorDivisaoOpcaoMultipleReportIndex.vm`, criamos uma função

	function onSelecionarClick(multiple) {  
        if (multiple) {  
            var url = bluesoftRaiz + "/Fornecedordivisaojsp/index.action?multiple=true";  
            openNewWindowResizeable(url, "fornecedor", 520, 600);  
        } else {  
            bluesoft.reportIndex.selecionarFornecedor();  
        }  
	}

e chamamos ela no clique do botão para passar `multiple`conforme o atributo

	onclick="onSelecionarClick($!{attributes.get('multiple')})"
