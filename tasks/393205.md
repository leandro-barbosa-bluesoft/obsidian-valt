Cenário Proposto

No Relatório de Produtos vamos incluir as seguintes novas colunas para o resultado da busca. Todas estas colunas novas devem ser incluídas como colunas disponíveis (não vem selecionadas por padrão para a busca ou exportação).

- Lastro: Número inteiro
- Camada: Número inteiro
- Quantidade por palete: Esse campo é a multiplicação de Lastro X Camada. Número inteiro.
- Peso Bruto: Número com 3 casas decimais
- Peso Líquido: Número com 3 casas decimais
- Comprimento (milímetros): Número inteiro
- Altura (milímetros): Número inteiro
- Largura (milímetros): Número inteiro
- Cubagem (m3): Trata-se de um cálculo de volume usando o comprimento, altura e largura. Como está em metros cúbicos, basta multiplicar comprimento, altura e largura (cada um convertido para metros multiplicando por 0,001). Como o resultado pode ser fracionado, podemos demonstrar aqui no formato de número com 3 casas decimais.
- Margem Adicional Logística (%): Valor com duas casas decimais (pois é assim que é salvo no banco apesar de na tela do cadastro demonstrar 3 casas). Este campo é salvo apenas no cadastro unitário, mas, quando o produto for uma caixa deste produto unitário, devemos mostrar também, mas buscando do cadastro unitário o mesmo valor.  
    Exemplo: Se a margem logística for 10% no produto unitário, todos os produtos caixa deste produto unitário também terão 10% nesta coluna.
- Custo Adicional Logística (R$): Valor com duas casas decimais (pois é assim que é salvo no banco apesar de na tela do cadastro demonstrar 3 casas). Este campo é salvo apenas no cadastro unitário, mas, quando o produto for uma caixa deste produto unitário, devemos mostrar também, mas multiplicando o custo adicional do cadastro unitário pelo fator estoque do produto caixa.  
    Exemplo: Se o custo logístico for R$ 1,25 no produto unitário, e tiver dois produtos caixa vinculados a ele (uma c/10 e outra c/50), então o custo logístico da caixa c/10 será 12,50 (1,25 x 10) e o da caixa c/50 será R$ 62,50 (1,25 x 50),

Como agora o relatório vai receber mais 11 novas colunas, o resultado pode ser ainda pior. Então devemos estabelecer um limite de colunas. Assim, vamos limitar a exportação para PDF em 35 colunas selecionadas (um pouco mais que a quantidade selecionada por padrão).

Para conhecimento, e para servir como base para este limite, temos atualmente limite definido em outros relatórios como o “Relatório de Conta Corrente do Produto” (menu 691) onde o limite é de 20 colunas:
